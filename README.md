# ThodHUB Registry

Публичный каталог программ ThodProd. Хаб читает catalog.json из main, а версии и пакеты — из GitHub Releases проектов.
Изображения лежат в assets/. Личные конфиги, базы и ключи сюда не добавляются.

Как добавить программу: прочитайте https://github.com/ThodProd/ThodHUB/blob/main/docs/MODULE-CONTRACT.md,
опубликуйте стабильный hub-vX.Y.Z с ZIP и thodhub-release.json, затем добавьте одну запись в apps.
После появления записи в main нажмите «Обновить каталог» в хабе. Следующие версии не требуют правки каталога.
Вход для нового агента: https://github.com/ThodProd/ThodHUB/blob/main/docs/AGENT-PROMPT.md
